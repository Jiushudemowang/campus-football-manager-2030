# 绿茵纪设计规范

## 设计理念

绿茵纪的视觉风格围绕三个关键词：

- **像素复古**：致敬早期足球游戏与 8-bit 像素美学，降低 AI 图像生成成本，同时形成强烈记忆点
- **情感叙事**：通过暖色调、胶片颗粒感、光影变化传递青春与体育精神
- **沉浸交互**：全屏叙事、打字机对话、分支选择，让观众成为故事的参与者

## 色彩系统

| 名称 | 色值 | 用途 |
|------|------|------|
| 绿茵绿 | `#1B5E20` | 主品牌色、强调按钮、标题 |
| 草坪绿 | `#4CAF50` | 背景渐变、成功状态、成就 |
| 夕阳橙 | `#FF6F00` | 情绪高光、重要选择、关键剧情 |
| 深空蓝 | `#0D47A1` | 夜晚场景、回忆片段、深沉情绪 |
| 暖沙金 | `#FFD54F` | 高光、奖杯、历史感 |
| 夜色黑 | `#121212` | 深色背景、边框 |
| 纸白 | `#F5F5F0` | 对话框、文字主色 |

## 字体

- 标题：`ZCOOL KuaiLe` / 站酷快乐体，活泼有力
- 正文：系统默认无衬线字体 + 思源黑体备选
- 像素数字：`Press Start 2P`（用于比分、年份、成就数字）

## 场景分类

| 场景类型 | 描述 | AI 生成 Prompt 关键词 |
|---------|------|---------------------|
| 足球场 | 比赛、训练主场景 | pixel art football field, green grass, 8-bit, sunset |
| 校园 | 招新、日常、回忆 | pixel art university campus, HUST, retro style |
| 更衣室 | 赛前动员、团队凝聚 | pixel art locker room, team huddle, motivation |
| 训练场 | 训练、备战 | pixel art training ground, early morning, fog |
| 城市夜景 | 失败后的思考、成长 | pixel art night city, neon lights, reflection |
| 颁奖典礼 | 胜利、历史时刻 | pixel art trophy ceremony, celebration, golden light |
| 历史档案 | 老照片、回忆 | pixel art old photo style, sepia tone, memory |

## 角色设计

角色以像素头像 + 球衣号码 + 年代标签呈现。头像使用 AI 生成像素风格半身像，统一尺寸 256×256px。

每个角色包含：
- 头像
- 姓名
- 号码/位置
- 年代标签
- 一句话简介
- 故事线入口

## UI 组件规范

- 按钮：圆角 8px，主色背景，悬停时轻微上浮 + 阴影
- 对话框：底部固定，半透明深色背景，左侧角色头像
- 选择支：卡片式，悬停时边框高亮
- 角色卡片：网格布局，悬停时显示简介
- 年份标签：像素字体，绿色徽章

## 动画规范

- 场景切换：淡入淡出 300ms
- 对话框出现：从底部滑入 200ms
- 打字机效果：每字 30ms
- 选择支出现：依次延迟 100ms 淡入
- 粒子效果：用于胜利、关键进球场景

## 响应式断点

- 桌面：≥1024px
- 平板：768px–1023px
- 手机：＜768px

移动端简化：
- 角色卡片改为 2 列
- 对话框高度适当增加
- 选择支改为垂直堆叠
- 复杂粒子效果降级
