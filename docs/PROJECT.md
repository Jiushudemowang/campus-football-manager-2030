# 作品说明文档

## 作品名称

**绿茵纪：AI 体育叙事引擎**

## 参赛信息

- **赛事**：第二届 AIGC 应用大赛
- **赛道**：创作赛道 · AIGC 应用作品
- **主题**：AI 赋能体育传播

## 作品简介

「绿茵纪」是一个基于 AIGC 的互动体育历史叙事平台。作品以华中科技大学新闻学院男子足球队 2016–2026 十年队史为首个案例，通过 AI 生成像素风格视觉、互动叙事、多分支选择与多结局系统，将一段真实的草根体育历史转化为可交互的数字化体验。

项目核心不是展示 AI 技术本身，而是探索「AI 如何赋能体育传播」——让那些可能被遗忘的民间体育故事，以更生动、更沉浸、更可参与的方式被记录、被传播、被记住。

## 创新点

1. **选题创新**：聚焦草根体育历史档案活化，避开职业赛事数据化赛道红海，体育 + AIGC 方向差异化明显。
2. **形式创新**：将体育历史从单向纪录片/报道，转变为多视角、多分支、多结局的互动叙事体验。
3. **技术创新**：多模态 AIGC 深度融合——AI 生成像素视觉、AI 生成场景图、互动叙事引擎、数据可视化。
4. **社会价值**：记录和传承民间体育文化，弘扬体育精神、团队协作与青春奋斗。

## 技术架构

```
前端：React 18 + TypeScript + Vite
状态管理：Zustand
样式：Tailwind CSS
动画：Framer Motion
数据可视化：ECharts
AI 图像生成：Trae API
头像占位：DiceBear pixel-art（可替换为 AI 生成）
部署：Vercel / Netlify 静态托管
```

## 核心功能

1. **角色选择**：6 位核心人物视角（吴志鸣、肖潇、吾尔肯、赵凌冬、杨云帆、王楷硕）
2. **互动叙事**：每位角色 4–5 个场景，含多分支选择与多结局
3. **多结局系统**：根据选择权重判定 good / normal / bad 结局
4. **存档系统**：支持手动存档、读档、自动保存进度
5. **数据可视化**：十年战绩时间线，展示球队从低谷到巅峰的完整曲线
6. **成就/图鉴**：收集结局、解锁角色
7. **跨平台适配**：支持桌面端与移动端 Web 访问

## AI 使用情况

详见 `AI_USAGE.md`。核心代码与叙事结构由团队手工完成，AI 主要用于：

- 像素风格场景图生成
- 角色头像生成
- 文案润色
- 代码辅助

## 作品运行方式

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

构建产物位于 `dist/` 目录，可部署到任意静态托管服务。
