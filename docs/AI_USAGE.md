# 绿茵纪 AI 使用报告

## 使用原则

- AI 仅作为创作辅助工具，不替代核心创意与叙事设计
- 核心代码、交互逻辑、数据结构由团队手工编写
- 所有 AI 生成内容均保留生成记录与提示词

## AI 使用范围

| 应用场景 | AI 工具 | 使用比例 | 说明 |
|---------|--------|---------|------|
| 像素风格场景图 | Trae API / 即梦 AI | 约 60% | 根据团队撰写的 prompt 批量生成 |
| 像素风格角色头像 | Trae API / 即梦 AI | 约 70% | 基于角色设定生成 |
| 剧情解说配音 | Edge TTS / ChatTTS | 约 80% | 为关键剧情节点生成语音 |
| 剧情文案润色 | 大语言模型 | 约 30% | 在团队撰写的史实基础上润色 |
| 代码辅助 | Claude Code / Copilot | 约 20% | 组件模板、样式调试、文档生成 |
| PPT 生成 | 自定义脚本 + AI 辅助 | 约 40% | 基于 `create_ppt.py` 改造 |

## 核心未使用 AI 的部分

- 项目整体创意与选题
- 角色与故事线结构设计
- 体育历史事实核查
- 核心交互逻辑与状态管理
- 最终艺术风格决策

## 生成记录

详见项目内 `assets/generated/` 目录中的 prompt 记录文件，以及 `docs/prompts/` 目录中的提示词模板。

## 人工修改比例

- 视觉素材：人工筛选约 70%，淘汰不合格生成图
- 剧情文本：人工重写约 60%，确保史实准确与情感一致
- 代码：人工编写约 80%，AI 仅用于辅助

## 备注

本作品遵循大赛关于原创性与 AI 使用的相关规定，AI 生成内容均已标注，团队对最终作品的内容与价值观负责。
