## 项目当前状态（2026-06-20）

- 项目定位：基于华科新闻男足十年队史的 AIGC 足球卡牌战棋游戏。
- 已完成模块：
  - 角色选择与互动叙事（StartPage / GameScreen / stories.ts）
  - 8×8 棋盘对战（ChessBoard / ChessMatchPage / chessRules.ts）
  - 校园球员卡收集（CollectionPage）
  - 训练成长系统（TrainingPage / trainingEngine.ts）
  - 阵容管理（SquadSetupPage）
  - 全局状态管理（gameStore.ts）
- 当前缺口：游戏内缺乏明确目标驱动，玩家进入 ManagerHub 后不知道下一步该做什么。

## 决策记录

- 任务类型第一版只支持「累计型」与「单次型」条件，避免过度设计。
- 奖励第一版只支持「解锁球员卡」与「增加成长点」，与现有系统自然衔接。
- UI 复用现有像素卡片风格与 Tailwind 色彩系统。
