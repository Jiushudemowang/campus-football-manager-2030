# 校园足球经理·2030

> 第二届 AIGC 应用大赛 · 创作赛道 · AI 赋能体育传播

## 项目简介

「校园足球经理·2030」是一款基于真实校园球员数据的 AIGC 足球卡牌战棋游戏。作品以华中科技大学新闻男足十年队史为核心数据基础，将中国传统象棋棋盘改造为足球场，黑白棋子化身两支球队，让玩家在 8×8 的棋盘上体验校园足球的战术对抗。

核心玩法：
- **卡牌收集**：基于真实校园球员数据生成球员卡
- **AI 球星对标**：为每张校园卡匹配风格相似的世界杯球星，生成能力雷达图对比
- **棋盘对战**：8×8 棋盘 = 足球场，黑白棋子 = 两支球队，结合象棋走位与足球战术
- **AI 模拟成长**：制定训练计划，培养校园球员挑战 AI 世界杯传奇队

## 项目特色

- **数据真实性**：基于华科新闻男足真实球员与比赛数据
- **AI 球星对标**：30 位世界杯球星库，AI 匹配风格相似度
- **象棋+足球创新**：传统棋盘改造为战术球场
- **数据新闻叙事**：用数据展示校园足球与世界巨星的差距与潜力
- **政策呼应**：响应"足球强国""全民健身"国家战略

## 技术栈

- React 18 + TypeScript + Vite
- Zustand 状态管理
- Tailwind CSS + 像素风格设计系统
- ECharts 数据可视化
- AI 图像生成 + LLM 球星对标

## 快速开始

```bash
npm install
npm run dev
```

## 项目结构

```
src/
  data/           # 球员卡、球星库、棋盘规则
  components/     # 棋盘、卡牌、对战界面
  pages/          # 首页、棋盘对战、球星对标、数据叙事
  stores/         # 全局状态
```

## AI 使用说明

作品中 AI 主要用于球星对标、能力雷达图生成、图像生成、事件生成。核心规则引擎与对战逻辑由团队手工实现。
